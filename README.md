# Livro de prints

O primeiro print fica no topo. Cada um seguinte entra logo abaixo.

## No Windows

O livro abre à direita. Deixe o telefone espelhado à esquerda. Recortar cobre a tela. Arraste um retângulo em qualquer lugar, inclusive na janela do telefone. O recorte entra no fim da pilha. Baixar PDF grava essa ordem, o primeiro em cima.

Na pasta deste repositório:

```
py -3 livro.py
```

Só precisa do Python 3 para Windows, com tkinter, que já vem no instalador de python.org. Não precisa instalar mais nada.

Esc cancela o recorte.

## No navegador

`index.html`, `styles.css` e `app.js` são a página. Ela usa o compartilhamento de tela do navegador e não desenha por cima de outras janelas.
